# Federal Laboratory Consortium for Technology Transfer (FLC)

> The FLC is the federally chartered network of more than 300 US federal laboratories, agencies and
> research centers, created by the Federal Technology Transfer Act of 1986 to move federally funded
> research into the wider economy. It publishes the Green Book (Federal Technology Transfer
> Legislation and Policy), runs the FLC Business search over federal lab technologies and
> facilities, and operates the interactive lab directory, T2 Toolkit and Learning Center.

This file was generated by API Evangelist (https://apievangelist.com) from the FLC's own public
surface on 2026-09-09. It is a third-party profile, not an FLC publication. FLC does not serve an
llms.txt of its own — https://federallabs.org/llms.txt redirects to /page-not-found.

## API

FLC publishes exactly one machine-readable API contract.

- [FLC Greenbook API — OpenAPI 3.0.0](https://api.federallabs.org/docs-json): the published
  contract, served by the API host itself. Title "Greenbook API (Public)", version 1.0. It ships
  `servers: []`; the host is `https://api.federallabs.org`, established by probe.
- [Swagger UI](https://api.federallabs.org/docs): the rendered reference.
- Base URL: `https://api.federallabs.org`
- One operation: `POST /v1/sections/search` (`SectionsController_searchSections`) —
  retrieval-augmented search over Green Book sections. Semantic retrieval, LLM rerank, then a
  generated answer returned with the source sections that produced it.
- Auth: an `app-key` request header, described in the contract as the mobile app key. **Not
  self-service** — there is no sign-up flow and no developer portal. A `bearer`/JWT scheme is
  declared in the contract but is not applied to the published operation.
- Rate limit: `X-RateLimit-Limit: 100` per `X-RateLimit-Reset: 60` seconds, observed on live
  responses. Undocumented by FLC.
- Errors: `{message, error, statusCode}` — not RFC 9457. Only a 200 is declared in the contract.

## What FLC does not publish

- No public developer portal. The developer API documentation page that search engines still index
  (https://federallabs.org/developer-api-documentation) now redirects to /page-not-found.
- No status page, changelog, deprecation policy, SLA, or pricing page.
- No SDKs or client libraries on npm, PyPI or any other registry.
- No MCP server. The Higher Logic community at engage.federallabs.org replies "The MCP server is not
  enabled for tenant FEDERALLABS" — the platform supports it; FLC has not enabled it.
- No A2A agent card, no /.well-known documents on any FLC host, no security.txt.
- No AsyncAPI, webhooks, gRPC or SOAP surface.

## Retired surfaces

- The FLC Business JSON:API at `https://www.federallabs.org/api/v1.0/` (laboratories, agencies,
  available technologies, technology areas and disciplines, regions) is gone — the path now returns
  a Cloudflare 301 to the site root.
- `https://business.federallabs.org/` returns Cloudflare 530 "Site is frozen". FLC Business search
  now routes to a vendor host, https://search.wellspringsoftware.net/auth/flc/login.
